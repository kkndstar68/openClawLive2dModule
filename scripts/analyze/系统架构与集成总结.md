## 🔄 数据流向详解

### 场景1：执行Alpha选股

```
Step 1: HTTP请求
GET /api/alpha

Step 2: 加载模块
├─ FidStock_v2_integration.py
├─ factors.py (TrendFactor, VolumeFactor, RSIFactor, etc.)
├─ analyzers.py (StockAnalyzer, ETFAnalyzer)
└─ multi_factor_scanner.py (MultiFactorScanner)

Step 3: 获取热点板块
HotSectorFetcher.fetch_hot_sectors()
返回: ['芯片', '新能源', '光伏', ...]

Step 4: 获取板块股票
for sector in hot_sectors:
    stocks = StockListFetcher.fetch_stocks_by_sector(sector)

Step 5: 分批获取行情（每批50只）
for batch in stocks:
    quotes = fetch_quotes(batch)  // 东方财富API

Step 6: 对每只股票获取K线
kline_data = fetch_kline(code, days=60)  // 60天K线

Step 7: 多因子评分
analyzer = StockAnalyzer()
score_result = analyzer.analyze(stock, kline_data, hot_sectors)
    ├─ TrendFactor.calculate(kline_data)       // MA、MACD
    ├─ VolumeFactor.calculate(stock, kline)   // 量比、换手
    ├─ RSIFactor.calculate(kline_data)        // RSI指标
    ├─ ValuationFactor.calculate(stock)       // PE/PEG
    └─ HotspotFactor.calculate(stock, sectors) // 板块热度
    
    CompositeScorer加权求和:
    score = (趋势×0.30 + 成交量×0.25 + RSI×0.15 + 估值×0.20 + 热点×0.10) × 100

Step 8: 过滤评分 >= 60分

Step 9: 计算买点和止损
buy_point_1 = MA20 + 1%
buy_point_2 = MA60 - 2%
stop_loss = 20日低点 - 2%
take_profit = 当前价 + (当前价 - 止损) × 2

Step 10: 计算EV（期望值）
EV = (评分贡献 + 换手贡献) / 2
评分贡献 = (评分 - 50) / 10
换手贡献 = 根据2-5%最优区间计算

Step 11: 排序和截断
sort by score DESC
return top 20 stocks

Step 12: 生成报告
{
    "timestamp": "2025-06-17T14:30:00",
    "推荐": [
        {
            "代码": "600000",
            "名称": "浦发银行",
            "现价": 10.5,
            "评分": 72,
            "EV": 2.5,
            "买点1": 10.2,
            "买点2": 9.8,
            "止损": 9.5,
            "止盈": 12.0,
            "策略": "趋势+估值"
        },
        ...
    ]
}

Step 13: 返回响应 + WebSocket推送
send_json(report)
push_to_pet("🎯 多因子选股: 浦发银行 72分...")
```

## 📊 评分系统对比

### 旧系统 (FidStock.py)

```
评分维度：
✓ MA5 > MA10 > MA20 排列 (简单判断)
✗ 不考虑成交量
✗ 不考虑RSI强弱
✗ 不考虑估值
✗ 不考虑热点

评分范围：0-100 (简单的if-else)
EV计算：公式不合理，基于价格变动百分比

问题：
- 成长股容易被低PE错杀
- 热点股票不突出
- 单维度评分容易失误
```

### 新系统 (多因子)

```
评分维度：
✓ 趋势 (MA排列 + 价格位置 + MACD) ────────── 权重30-40%
✓ 成交量 (量比 + 换手 + 成交量同比) ───────── 权重25-30%
✓ 强弱 (RSI14) ──────────────────────────── 权重15-20%
✓ 估值 (PE/PEG，分类评估) ─────────────────── 权重15-20%
✓ 热点 (板块热度) ────────────────────────── 权重5-15%

评分范围：0-100 (标准化的加权平均)
EV计算：基于评分和换手率的期望值模型

优势：
- 分类估值：成长股和稳定股不同标准
- 多维度平衡：综合多个技术指标
- 自适应权重：熊市强化估值，牛市强化趋势
- 热点识别：自动跟踪板块轮动
```

## 🎯 各个模块的职责

| 模块 | 职责 | 输入 | 输出 |
|-----|------|------|------|
| **factors.py** | 计算各个技术因子 | K线数据、股票数据 | 因子评分(0-35/30/10/20) |
| **analyzers.py** | 根据资产类型分析 | 股票/ETF数据+K线 | 综合评分+买卖点 |
| **multi_factor_scanner.py** | 主扫描控制流程 | 代码列表 | 推荐股票/ETF列表 |
| **config.json** | 配置参数 | - | 权重、阈值、ETF列表 |
| **FidStock_v2_integration.py** | 接口兼容层 | 原有接口 | 报告格式(与原版兼容) |
| **pet_stock_monitor.py** | HTTP服务 | HTTP请求 | JSON响应 |
| **main.ts** | 前端展示 | JSON数据 | UI界面 |

| **后向兼容** | ✅ | ✅ 完全兼容 |
